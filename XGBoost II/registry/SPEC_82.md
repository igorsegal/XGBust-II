# Описание 82 столбцов таблиц индикаторов

Редакция 2026-11-25. Составлено по `tools/build_indicators.cpp` и `registry/tester/indicators.h`.

## Файлы

- `BAZA\<инструмент>\indicators\<инструмент>_<TF>_dev.bin` — бары 2020–2024; `_holdout.bin` — с 2025 (только для экзамена).
- Формат EQIND001: заголовок 64 байта; int64 время открытия бара [n]; затем 82 столбца float32 подряд, по n значений. Порядок имён — `columns.txt`.
- Строка известна в момент закрытия бара: время + длина бара (W1: время + 7 дней). Старший таймфрейм подключается только по уже закрытым строкам.
- Пустое значение — NaN.

## Обозначения

O H L C — цены Bid бара; V — тиковый объём (число тиков); **A** — ATR14, простое среднее истинного диапазона за 14 баров; TP = (H+L+C)/3; `[k]` — k баров назад; σ — стандартное отклонение генеральной совокупности. `_dist` — расстояние от цены до уровня в ATR (плюс: цена выше).

## Что учесть при обучении

- Точные повторы: 7 = 0, 28 = 1; на H1 ещё 80 = 76. Лишние убрать из входов модели.
- Постоянные столбцы: на H1 — 79; на D1 — 76, 78, 79, 80; на W1 — 76–80.
- Прогрев до 77 баров своего таймфрейма: на D1 EURUSD все столбцы заполнены с 2020-04-17, на W1 — с 2021-06-27.
- Пивоты в самом начале истории считаются по неполному первому дню или неделе.
- Для AD, HIGHEST, LOWEST отдельных столбцов нет: они повторяют CMF и границы Дончиана.
