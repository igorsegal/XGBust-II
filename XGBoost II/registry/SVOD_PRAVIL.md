## 3. Критерии и издержки

Взяты из реестра, заморожены 2026-11-24.

| Что | Значение |
|---|---|
| Нетто после издержек | больше нуля |
| Профит-фактор | не ниже 1,3 |
| Сделок | не меньше 100 |
| Выход | через 24 бара |
| Стоп | 2 × ATR(14) |
| Издержки | спред из бара + комиссия 7 USD за лот |

**Утверждено 2026-11-25:**
1. Действуют только эти критерии; прежние из `AGENTS.md` (сделок вне выборки не меньше 150, доля побед не меньше 56% или положительное матожидание) отменены.
2. Критерии считаются по сумме всех проверочных кусков; правило принято, только если выполняет их и на разработке, и на экзамене.
3. Экзамен открывается один раз на замороженную версию правила. После любой переделки это новая версия, и прежний экзамен для неё уже не чистый.

Как это делает тестер: экзамен открывается только ключом `--exam`, только для основного теста, прошедшего разработку, и один раз для каждой пары и таймфрейма без изменения правила. Открытия записываются в `exam_log.txt`. Правку кода правила на C++ тестер сам не заметит: переделанному правилу нужно дать новый ID.

Для USDJPY комиссия в долларах переводится в иены по цене входа; для золота лот 100 унций.

22 прототипных правила: на каких датах их нашёл старый майнер, в этой редакции не проверено. Если он видел 2025–2026, экзамен для них не чистый.

Правила со своими входом, стопом и целью (`kind: strategy`, в конфиге `"exits": {"by_rule": true}`): общий выход через 24 бара и стоп 2×ATR к ним не применяются, выходы описаны в `specs\<ID>.md`. Критерии, издержки и окна те же. Таких правил три: `LONDON_TRAP_01`, `CLASSIC_TRACE_01`, `NY_CONTINUATION_01`.

`XGB_WF_02` (утверждено 2026-11-25): выход через 120 баров и стоп 4×ATR(14) вместо общих 24 и 2×ATR. Критерии, окна и издержки те же; свопы не учитываются (`specs\XGB_WF_02.md`).

## 4. Внесение нового правила

1. `python add_rule.py НОВЫЙ_ID "Название"` (для правила строкой условия добавить `--expr`).
2. Заполнить запись в `rules_registry.json`: источник, условия, параметры, допущения.
3. `python validate_registry.py` — без ошибок.
4. Проверка причинности (`--selftest`): расхождений нет.
5. Прогон по окнам разработки (`RUN_TESTS.bat`); затем, если прошло, экзамен (`--exam`).
6. `python record_results.py` — статус в реестре.

Подробности формата: `registry/README.md`. Старший таймфрейм берётся только по закрытому бару.
