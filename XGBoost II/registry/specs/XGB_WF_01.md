# XGB_WF_01 — XGBoost на таблице 82 столбцов, H1

Источник: этап 3 согласованного плана. Утверждено пользователем 2026-11-25: запустить XGBoost на готовых столбцах; настройки ниже выбраны исполнителем.

**Этот текст записан до первого прогона. После прогона ничего не меняется: любая переделка (порог, настройки, столбцы, таймфрейм, цель) — новый ID.**

## Что проверяется

Может ли модель по 6 месяцам истории выбирать на следующих 2 месяцах входы, которые после расходов приносят прибыль.

| Что | Значение |
|---|---|
| Инструменты | EURUSD, GBPUSD, USDJPY, AUDUSD, XAUUSD, каждый отдельно |
| Таймфрейм | H1 |
| Входы модели | 78 столбцов H1 из `SPEC_82.md`: все, кроме повторов 7, 28, 80 и постоянного 79. Другие таймфреймы не подключаются |
| Что предсказывает | результат сделки в R (R = 2 × ATR14) после спреда и комиссии; отдельная модель для покупки и отдельная для продажи |
| Выход (общий по своду) | через 24 бара или по стопу 2 × ATR(14) |
| Вход | если прогноз не меньше 0,10 R; из двух сторон берётся больший прогноз, при равенстве — покупка. Вход по открытию следующего бара, одна позиция на инструмент |
| Окна | обучение 6 месяцев, проверка 2, сдвиг 2; разработка июль 2020 – декабрь 2024 (AUDUSD с окна 3) |
| Зазор | в обучении только примеры, у которых все 24 бара сделки закрылись до начала проверочного отрезка |
| Расходы | спред из бара входа и выхода + комиссия 7 USD за лот (как в тестере) |
| Критерии | сделок не меньше 100, нетто больше нуля, профит-фактор не ниже 1,3 |

## Настройки модели (без подбора)

XGBoost 2.1.4, регрессия с квадратичной ошибкой, 200 деревьев, глубина 3, шаг 0,03, доля строк 0,8, доля столбцов 0,8, min_child_weight 50, reg_lambda 1, seed 42, один поток, tree_method hist. Пустые значения столбцов модель получает как пропуски. Внутри обучающего отрезка отложенной выборки и подбора настроек нет.

## Что учесть при чтении результата

- Проверяется пять инструментов сразу: прохождение одного из пяти может быть случайностью. Решает закрытый экзамен, который здесь не открывается.
- Экзамен (с 2025 года) программа обучения не читает: файлы `_holdout.bin` не открываются, бары обрезаются на 2024-12-31. Открытие экзамена для этого правила пока не запрограммировано.

## Проверки

1. Сделки считаются тестером C++ по сигналам модели и независимо на Python; итог и каждое окно должны совпасть.
2. Для каждого окна все бары и столбцы с начала проверочного отрезка заменяются мусором, модель обучается заново: прогнозы на настоящих проверочных данных не должны измениться.
3. Построение столбцов проверяет само себя на заглядывание в будущее на укороченной истории.
